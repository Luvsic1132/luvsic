# 搭建你自己的同步仓库

> Luvsic 默认是**纯本地播放器**，不需要任何账号。
> 这份教程是给想「手机和电脑同步」的人看的——你需要一个**自己的** GitHub 仓库来存数据。
>
> 全程免费，大约 5 分钟。

---

## 为什么需要自己的仓库

Luvsic 的同步不经过任何服务器。你的曲库索引、歌单、好友列表、听歌时长，直接写进一个 GitHub 仓库里。

**用你自己的仓库**意味着：

| | 说明 |
|---|---|
| 数据归你 | 别人看不到，项目作者也看不到 |
| 不依赖作者 | 作者的仓库哪天没了，你的数据还在 |
| 免费 | GitHub 私有仓库免费，容量足够存几万首歌的索引 |

⚠️ **不要把你的 Token 发给任何人**，包括项目作者。它等同于你 GitHub 账号的钥匙。

---

## 第一步：创建仓库

1. 打开 https://github.com/new
2. **Repository name** 填一个名字，例如 `luvsic-data`
3. **Private**（私有）或 Public（公开）都可以——**推荐 Private**
4. **不要**勾选 "Add a README file"、"Add .gitignore"、"Choose a license"
5. 点 **Create repository**

创建完你会看到一个空仓库页面，地址栏里是：

```
https://github.com/你的用户名/luvsic-data
                            └────────┬────────┘
                              记住这半段
```

**你需要记住的格式是 `你的用户名/luvsic-data`**（中间是斜杠，不要带 `https://github.com/`）。

---

## 第二步：生成 Token

1. 打开 https://github.com/settings/tokens/new
2. **Note** 填：`luvsic-sync`
3. **Expiration** 选 `No expiration`（永不过期）或 `90 days`（更安全，到期重生成）
4. 在 **Select scopes** 里，只勾选 **`repo`** 这一个大项
   - 勾了父级 `repo`，下面 5 个子项会自动全选，这是正常的
   - 其他所有权限都不用勾
5. 拉到最下面，点 **Generate token**
6. **复制出现的 `ghp_` 开头的一长串** —— 这个页面只显示一次，关掉就再也看不到了

> 如果你之前生成过 Token 但没勾 `repo`，Luvsic 会提示「令牌无效或没有 repo 权限」。
> 回 https://github.com/settings/tokens 删掉旧的，重新生成一个。

---

## 第三步：在 Luvsic 里填入

### 桌面版

1. 打开 Luvsic（默认直接进主界面，不会弹登录框）
2. 点左下角 **设置**（齿轮图标）
3. 找到 **账号与同步** 卡片
4. 点 **「连接自己的仓库…」**
5. 填入：
   - **仓库**：`你的用户名/luvsic-data`
   - **Token**：`ghp_` 开头那一长串
6. 点 **连接**

成功的话会提示「已连接 你的用户名/luvsic-data」，然后自动同步一次。

### 安卓版

路径一样：**设置 → 账号与同步 → 连接自己的仓库…**

---

## 第四步：在第二台设备上连接

在另一台设备（手机或另一台电脑）上重复第三步，**填完全相同的仓库和 Token**。

两台设备就连上了。之后：

- 在一台上加歌单 → 另一台同步后能看到
- 在一台上听歌 → 排行榜时长累加
- 互加好友 → 能看到对方正在听什么

---

## 数据存在仓库里的什么位置

```
你的仓库/
├── users/
│   └── <你的设备ID>/
│       ├── data.json        曲库索引 + 歌单
│       ├── profile.json     昵称 + 头像
│       └── stats.json       听歌时长
├── accounts.json            设备与好友关系
└── updates.json             版本信息（可忽略）
```

**这些文件都是普通 JSON，你可以直接在 GitHub 网页上打开看，也可以手动备份。**

## 常见问题

### 提示「令牌无效或没有 repo 权限」（401/403）

Token 没勾 `repo`，或者已经被你删了。重新生成一个，勾上 `repo`。

### 提示「仓库不存在或令牌无权访问」（404）

三个可能：
1. 仓库名写错了（必须是 `用户名/仓库名`，中间一个斜杠）
2. 仓库是别人的（只能用自己账号下的仓库）
3. Token 属于另一个 GitHub 账号

### 同步很慢或失败

GitHub 在部分网络环境下访问不稳定。Luvsic 会重试，也可以点「立即同步」手动再试一次。

### 我不想同步了

**设置 → 账号与同步 → 退出登录**。

这只会删掉本机保存的 Token，**不会删除仓库里的数据**。想彻底删数据，去 GitHub 上删那个仓库。

### 我想换一个仓库

先「退出登录」，再「连接自己的仓库」，填新的地址。

### 两台设备显示的曲目路径不一样

正常。同步的是**歌单结构**（歌名 + 歌手 + 时长），不是文件本身。每台设备按自己的路径匹配本地文件，匹配不到就标「离线」。

## 安全提醒

| 要做 | 不要做 |
|---|---|
| Token 只填在 Luvsic 里 | 把 Token 发给别人 |
| 定期检查 https://github.com/settings/tokens | 在截图里露出 Token |
| 怀疑泄漏就立刻删掉重生成 | 用同一个 Token 干别的事 |

**Token 在本机存在哪里**：

| 平台 | 位置 |
|---|---|
| Windows | `<Luvsic目录>\data\sync.json` |
| Android | 应用私有目录 `files/data/sync.json` |

这个文件不会上传，`.gitignore` 已排除。

---

## 完全不想用云端？

**那就什么都不用做。**

Luvsic 打开就是本地播放器，播放、曲库、歌词、EQ、变调、壁纸、备份恢复全部可用。

同步只是一个可选的增强，不是必须的。

## 附录：和好友一起用（想有好友/排行榜才需要看）

**先明确一件事**：

| 你想要的 | 需要怎么做 |
|---|---|
| 只是自己手机电脑同步 | 连接到第三步就够了，**不用管这节** |
| 想加好友、看排行榜、互相分享歌单 | **必须几个人连同一个仓库** |

原因：好友数据存在仓库里的 `accounts.json`，各人自建仓库时谁也看不见谁。

### 做法（推荐：GitHub Collaborator）

**由一个人建仓库（就是你的朋友里最闲的那个）：**

1. 他按上面第一、二步建好仓库、生成 Token
2. 打开仓库 → **Settings** → 左侧 **Collaborators** → **Add people**
3. 输入你的 GitHub 用户名，发出邀请
4. 你收到邮件，接受邀请

**然后你自己：**

5. 生成**你自己的** Token（`repo` 权限）
6. 在 Luvsic 里填 **同一个仓库地址** + **你自己的 Token**

**这样：**
- 每人用自己的 Token，**谁也不用把 Token 给别人**
- 数据都写进同一个仓库，好友功能生效
- 任何一个人退出，不影响其他人

### 然后加好友

1. 打开 Luvsic → **好友与排行**
2. 上面显示你的 **8 位好友码**
3. 把好友码发给朋友
4. 朋友在同一个位置输入你的好友码 → 发申请
5. 你在「好友申请」里点同意

**好友码 vs 账号 ID 的区别**：好友码专门用来加好友，别人拿到你的好友码也**登不进你的账号**。

### 不想共享了怎么办

- 想退出：在 Luvsic 设置里「退出登录」，数据还在你自己设备上
- 仓库主可以把你的 Collaborator 权限移除
- 彻底不想共享：自己建一个新仓库，重新连接

**注意**：共享仓库意味着**好友能看见你的曲库索引、歌单、听歌时长**。不想暴露这些就别共享。
